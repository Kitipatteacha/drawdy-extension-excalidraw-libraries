# Changelog

## 0.1.0

- First release: browse and search the community libraries from
  libraries.excalidraw.com, and add any item to the board as editable shapes.
- Items that use something Drawdy shapes can't show go in as a picture, and
  any item can be added as a picture.
- Open a `.excalidrawlib` or `.excalidraw` file from your device.
